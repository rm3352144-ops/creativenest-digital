# CreativeNest Digital

**Create More. Learn More. Live Creatively.**

CreativeNest Digital is a storefront concept for educational and creative digital products.

## Collections
- Preschool workbooks and alphabet/number tracing resources
- Printable worksheets and kids' activities
- T-shirt and hoodie artwork
- Printable Christmas and greeting cards
- Digital product bundles

## Project files
- `index.html` — responsive storefront homepage

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The public website URL will appear in the Pages settings.

## Before accepting orders
Add real product images and downloadable files, accurate prices, a working checkout/payment provider, delivery instructions, contact details, refund terms and privacy information. GitHub hosts the website files; it does not itself process customer payments or deliver paid downloads.
